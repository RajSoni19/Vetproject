# Cleanup candidate audit — 23 October 2026

This audit preserves a short record before cleanup. It does not delete database
data, migrations, credentials, document originals, recovery material, or the
immutable backup.

## Method

On 23 October 2026, every non-preview file in `docs/` was searched by both its
repository-relative path and basename across `app`, `components`, `lib`,
`scripts`, `tests`, `database`, `infra`, active configuration, and the rest of
`docs/`. The audit excluded generated directories, environment files, database
clusters, recovery directories, and image previews. A zero result means no
literal in-repository reference was found; it does not establish that a
historical report has no audit or recovery value.

## Proven disposable artifacts

| Path | Evidence | Action |
| --- | --- | --- |
| `.next/` | Ignored Next.js build output. It is regenerated by `next build` or `next dev`; no application source imports it. | Remove only after the final build/test run, and only while no local Next.js process is using it. |
| `tsconfig.tsbuildinfo` | Ignored TypeScript incremental cache. The project typecheck explicitly disables incremental output. | Remove after final validation. |
